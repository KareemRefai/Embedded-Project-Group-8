This project implements an autonomous line-following and obstacle-avoidance robot using a PIC16F877A microcontroller. The system integrates analog and digital sensors, including an LDR for ambient light detection and infrared sensors for line tracking and obstacle detection, to navigate complex paths and mazes. Motor control is achieved via PWM-driven DC motors with configurable speed and direction, while a servo mechanism enables interaction with environmental elements. The software architecture includes precise timing functions, ADC reading, and adaptive movement algorithms to ensure responsive navigation and safety, making it suitable for robotics education, prototyping, and autonomous navigation experiments.
